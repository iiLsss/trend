## Context

当前项目中的指标卡片（如黄金趋势的“20日均线”、“日收益率波动率”，中东冲突的“平民伤亡”等）仅有简单的标题和副标题。对于非金融或非地缘政治专业的普通用户来说，这些术语显得过于生硬，缺乏上下文解释，导致用户无法准确理解这些数据对判断趋势的实际意义。

## Goals / Non-Goals

**Goals:**
- 设计并实现一个轻量、响应式的 Tooltip 组件。
- 在 PC 端支持鼠标悬停（Hover）触发，在移动端支持点击（Click）触发。
- 梳理并撰写黄金趋势和中东冲突核心指标的“大白话”解释文案。
- 将 Tooltip 无缝集成到现有的指标卡片标题旁边。

**Non-Goals:**
- 引入重量级的 UI 组件库（如完整的 Material UI 或 Ant Design），保持项目轻量。
- 为页面上的每一个文字都添加解释，仅针对核心的、容易产生理解门槛的指标。

## Decisions

**1. Tooltip 组件技术选型**
- *方案 A (选中)*: 使用 `@radix-ui/react-tooltip`。
  - *Rationale*: Radix UI 提供了无样式的底层无障碍交互逻辑，完美支持 PC 端 Hover 和移动端 Touch/Click 事件，且体积小，非常适合我们自定义 Tailwind 样式的需求。
- *方案 B*: 纯 CSS 实现 (Hover) + 简单 React State (Click)。
  - *Rationale*: 虽然不需要依赖，但处理移动端点击外部关闭、屏幕边缘防溢出等边界情况比较繁琐，不如直接使用成熟的 headless UI。

**2. 交互设计**
- **触发器 (Trigger)**: 在指标标题右侧放置一个灰色的、小巧的 `HelpCircle` (Lucide React) 图标。
- **展示内容 (Content)**: 黑色半透明背景，白色文字，字体较小（`text-xs`），最大宽度限制（如 `max-w-xs`），确保在移动端不会超出屏幕。
- **动画**: 简单的淡入淡出（Fade in/out）效果。

**3. 文案设计 (大白话解释)**
- **黄金趋势**:
  - *20日均线*: “代表过去一个月左右的平均买入成本。如果当前价格高于它，说明短期内大家都在赚钱，趋势向好。”
  - *60日均线*: “代表过去三个月（一个季度）的平均买入成本。用来判断中长期的基本方向。”
  - *日收益率波动率*: “类似股市的恐慌指数。数值越大，说明近期金价上蹿下跳越厉害，风险越高；数值越小，说明价格走势越平稳。”
- **中东冲突**:
  - *冲突升级级别*: “综合评估当前交火的激烈程度。数值越高，说明打得越凶，局势越危险。”
  - *外交进展状态*: “反映国际社会劝架的效果。如果状态停滞或恶化，说明和平解决的希望渺茫。”
  - *停火达成概率*: “基于各方态度算出的和平可能性。概率越低，说明短期内停战的希望越小。”
  - *地区外溢影响*: “评估冲突是否把周边国家也卷了进来。受影响国家越多，说明事情闹得越大。”

## Risks / Trade-offs

- [Risk] 移动端 Tooltip 可能会被手指遮挡或超出屏幕边界。
  - *Mitigation*: Radix UI 自带碰撞检测（Collision detection），会自动调整弹出位置（上下左右）以适应屏幕边缘。
- [Risk] 引入新的依赖（Radix UI）会略微增加打包体积。
  - *Mitigation*: Radix 是按需引入的模块化设计，对整体体积影响极小，带来的交互稳定性和无障碍（a11y）收益远大于成本。
